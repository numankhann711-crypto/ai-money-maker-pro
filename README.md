# AI Money Maker Pro

A beginner-friendly Claude Skill for planning ethical online earning activities, freelancing services, client proposals, content work, and simple business workflows.

> **No income is guaranteed.** This project helps with planning and writing; it does not create jobs or guarantee clients.

## What's included

- `SKILL.md` — the main skill instructions
- `templates/proposal-template.md` — a reusable proposal outline
- `templates/portfolio-plan.md` — a simple starter portfolio plan

## Use with Claude

1. Download this repository as a ZIP (or download the skill ZIP attached to this project).
2. In Claude, open **Settings → Capabilities → Skills** (the exact labels may vary).
3. Upload the ZIP if custom Skills are available on your plan/workspace.
4. Enable the skill and test it with:  
   `I have an Android phone and 1 hour a day. Suggest one realistic online service I can learn.`

Claude's custom Skills availability can depend on plan and workspace settings. If the Skills option is unavailable, copy `SKILL.md` into a conversation and ask Claude to follow it.

## Put it on GitHub

1. Sign in to GitHub and create a **new public repository** named `ai-money-maker-pro`.
2. Upload the files and folders from this project.
3. Add a short repository description: `A practical AI skill for ethical online earning plans and freelance workflows.`
4. Do not upload passwords, API keys, personal documents, or private client data.

## Beginner starting point

If you are new, start with one service, make three sample portfolio pieces, then contact a small number of relevant potential clients with honest, personalized messages. Do not pay anyone to "unlock" a job.

## Safety

Review skill instructions before installing. Only install skills from sources you trust. This skill does not request credentials, move money, send messages, or perform external actions by itself.
