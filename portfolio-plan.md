# 3-Piece Starter Portfolio

Choose one service and create three original samples.

| Sample | What to make | What it demonstrates |
|---|---|---|
| 1 | A simple example for a fictional business | Basic quality and style |
| 2 | A second example for a different audience | Adaptability |
| 3 | A before/after or mini case study clearly labelled as a practice project | Process and reasoning |

## Rules
- Label practice work as a sample; never imply a real client hired you.
- Use assets you own, have permission to use, or that are properly licensed.
- Keep each sample focused on one skill.
- Ask for feedback and improve the weakest sample.
